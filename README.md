# NEBULANCE: As Sementes do Colapso

Plataforma 2.5D offline para Windows (Godot 4.7.2, GDScript tipado). Especificação: PDF "Prompt Mestre Supremo" (fora do repositório).

Estado: **Fases 4 e 5** — Sylvara e Cristália completas em graybox (fases 01-12, secretas S01 e S02, chefes Vyrkan e Zythra), Mapa Galáctico, visual 3D de primeira passagem e configurações gráficas; 436 checagens automáticas e um bot que completa cada fase. Faltam os planetas 3 a 6, playtest humano e arte final. Para jogar: `build/nebulance_phase3.exe` (gerado pela exportação) ou abra no Godot e execute (F5).

## Rodar
```
C:\Ferramentas\Godot\Godot_v4.7.2-stable_win64_console.exe --headless --path . --import
C:\Ferramentas\Godot\Godot_v4.7.2-stable_win64_console.exe --headless --path . --script res://tests/run_tests.gd
```
Documentação em `docs/` (ENVIRONMENT, TOOLS_AND_MCPS, REQUIREMENTS_MATRIX, ADR, REPORTS).
